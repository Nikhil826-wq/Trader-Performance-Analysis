# 📊 Trader Performance & Market Sentiment Analysis

## 📌 Objective
To analyze the relationship between trader performance and Bitcoin market sentiment (Fear & Greed Index).

## 🛠️ Tools Used
- Python  
- Pandas  
- Matplotlib  

## 📂 Datasets Used
1. Historical Trader Data  
2. Fear & Greed Index Data  

## 📊 Analysis
- Profit/Loss Distribution  
- Buy vs Sell Comparison  
- Trade Size vs Profit  
- Sentiment vs Trader Performance  

## 📈 Key Findings
- Extreme Fear leads to losses  
- Greed phases show higher profit  
- Market sentiment affects trading behavior  

## 🧠 Conclusion
Market sentiment plays a key role in trading decisions and profitability.
## 🔍 Insight Example
Extreme Fear conditions resulted in average losses (~ -23), while Greed phases showed positive profitability (~ +7 to +8).
